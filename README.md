## 备份内容

| 目录 | 内容 |
| --- | --- |
| `frontend/dist/` | 从 `/data/web/dist` 复制的当前前端部署文件，33 个文件 |

## 范围

原备份范围是网页与其单个 Nginx 路由；后端 Java 包、后端源码、管理端页面、完整 Nginx 配置和数据库未包含。当前功能分支更新了线上网页与该路由，并新增独立预警服务。服务器上的原 Java 后端继续使用原有部署。

前后端完整快照的抓取被自动审批拒绝，完整后端备份仍需单独确认。这里的恢复脚本只恢复上述网页范围。
